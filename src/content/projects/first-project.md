This is my first project on the hub. It's a static site built with **Astro**,
containerized with **Docker**, and reverse-proxied through **Nginx** with
Let's Encrypt SSL on an **AWS EC2** instance.

## What I Learned

- How to configure Nginx as a reverse proxy
- How to build a multi-stage Dockerfile for static sites
- How to use Astro content collections for structured content
